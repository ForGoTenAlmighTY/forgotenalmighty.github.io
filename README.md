# Victor Leping — Developer Portfolio

A clean, responsive single-page developer portfolio built to showcase my projects, technical skills, professional experience, and academic qualifications as a **Junior C# / .NET Developer**.

🔗 **Live Site:** [https://forgottenalmighty.github.io](https://forgottenalmighty.github.io)

---

## Features

- **Dark & Light Mode Toggle:** Defaults to a dark developer theme with a persistent light/dark mode switch.
- **Interactive Project Showcase:** Filter projects by category (`All`, `C# & .NET`, `Web & PHP`, `Mobile & Java`) and open detailed modals for each build.
- **Responsive Layout:** Mobile-first navigation bar with a collapsible mobile menu and fluid layouts across desktop, tablet, and mobile screens.
- **Developer Profile Card:** C#-styled profile snippet and quick highlight stats in the hero section.
- **Skills, Experience & Education:** Structured breakdown of technical skills, core strengths, ScopeIT and Outlier experience, and academic timeline with Distinction highlights.
- **Contact Section & Utilities:** One-click email copy with toast feedback, direct social links, and a validated contact form that opens a pre-filled email.
- **Zero-Build Architecture:** Everything lives in a single `index.html` file—no build tools or bundlers required.

---

## Tech Stack

- **Markup:** HTML5
- **Styling:** Tailwind CSS (via CDN)

- **Typography:** Inter & JetBrains Mono (Google Fonts)

## Running Locally

Because this is a static single-file site, you can run it locally in seconds:

1. Clone the repository:
   ```bash
   git clone https://github.com/ForGoTenAlmighTY/ForGoTenAlmighTY.github.io.git
   ```
2. Open the folder and double-click `index.html` to launch it in your browser, or serve it with the VS Code **Live Server** extension.

---

## Deployment

This portfolio is deployed using **GitHub Pages** directly from the `main` branch (`/` root folder). Any commit pushed to `index.html` automatically updates the live site.
